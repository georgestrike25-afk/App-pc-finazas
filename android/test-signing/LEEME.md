# Clave de firma de PRUEBA

`prueba.jks` (contraseña `prueba-finanzas`, alias `prueba`) es una clave **pública y solo para pruebas**:
permite que cada APK nuevo se instale encima del anterior sin perder datos.

Como está publicada en el repositorio, cualquiera podría firmar un APK con ella. No instale APK
de este proyecto que no provengan de la página de Releases del repositorio.

Para usar una clave privada definitiva (recomendado antes de cargar datos reales):
ver la sección "Firma definitiva del APK" del README. Al cambiar de clave hay que desinstalar la
versión de prueba (exporte antes una copia de seguridad).
